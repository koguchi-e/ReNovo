# Create GitHub Issue

ReNovoリポジトリのGitHub Issueを、安全に起案・登録・設定する。

## 事前確認

1. 現在のGitリポジトリ、リモート、ブランチ、作業ツリーを確認する。
2. リポジトリルートの`AGENTS.md`を読み、プロジェクト固有の開発・GitHub運用ルールに従う。
3. 関連する既存Issueを検索し、重複、既存の方針、関連Issue番号を確認する。重複の可能性がある場合は、作成せずに候補をユーザーへ示す。

## Issue案の作成

- ユーザーの依頼、既存の実装、関連Issueを基に、簡潔で内容を表すタイトルと本文案を作成する。
- 本文には、必要に応じて背景、対応内容、受け入れ条件、影響範囲、関連Issueを含める。
- 作成前に、タイトル・本文・対象リポジトリ・設定予定のProject、Status、Labelをユーザーへ提示する。

## 承認と登録

- Issueの登録は、ユーザーから明示的な承認を得た後にのみ実行する。
- Projectへの追加、Statusの設定、Labelの設定も、それぞれユーザー承認後にのみ実行する。
- Project、Status、Labelが指定されていない場合は、既存のProject、利用可能なStatus、既存Labelを調査する。調査後も選択が確定できない場合は、ユーザーに確認する。推測で設定しない。
- 実際の登録操作を行う直前に、対象リポジトリ、Issue内容、設定対象を再確認する。

## 完了報告

- 作成したIssueのURLを報告する。
- 設定したProject、Status、Labelと、実行した操作を報告する。
- 承認待ちで実行しなかった操作、または未指定で設定しなかった項目があれば明記する。
