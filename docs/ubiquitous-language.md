# ユビキタス言語

ReNovoで使用する主要な用語と、その意味を定義します。
画面、仕様、テスト、コードで共通の認識を持ち、表現の揺れを防ぐことを目的としています。

## 用語一覧

| 用語                 | 定義                                                                           | コード上の対応               |
| -------------------- | ------------------------------------------------------------------------------ | ---------------------------- |
| **状況整理**             | 現在の状況、解決したい問題、達成したい目標を入力し、状況を明確にする一連の操作 | `Situation`                  |
| **現在の状況**           | ユーザーが現在置かれている状況や、実際に起きた出来事                           | `Situation#fact`             |
| **解決したい問題**       | 現在の状況から解決したい困りごとや課題                                         | `Situation#problem`          |
| **達成したい目標**       | 問題が解決したあとに目指す状態                                                 | `Situation#goal`             |
| **タスク**               | 状況整理の内容をもとに、AIが提案する具体的な行動                               | `Task`                       |
| **タスクリスト**         | 一つの状況整理に対して提案・追加されたタスクの集合                             | `Situation#tasks`            |
| **最初に取り組むタスク** | タスクリストのうち、最初に実行するタスク                                       | `Task#position = 1`          |
| **状況整理の履歴**       | 過去の状況整理と、それに対応するタスクリスト                                   | `SituationsController#index` |

「現在の状況」「解決したい問題」「達成したい目標」は、入力欄と詳細画面で使用する正式な項目名です。
入力画面の質問見出しでは、ユーザーが回答しやすい問いかけに言い換えて表示します。

| 正式な項目名 | 入力画面の質問見出し |
| --- | --- |
| **現在の状況** | 今どんなことが起きていますか？ |
| **解決したい問題** | 今一番困っていることは何ですか？ |
| **達成したい目標** | どうなったら、少し前に進めそうですか？ |

## 使用しない用語

| 使用しない用語 | 理由                                                               | 使用する用語   |
| -------------- | ------------------------------------------------------------------ | -------------- |
| ふりかえり     | 完了した出来事を改めて確認する意味に受け取られるため               | **状況整理**       |
| 行動整理       | 入力段階では行動ではなく、現在の状況・問題・目標を整理しているため | **状況整理**       |
| 履歴一覧       | 何についての履歴か分からないため                                   | **状況整理の履歴** |
